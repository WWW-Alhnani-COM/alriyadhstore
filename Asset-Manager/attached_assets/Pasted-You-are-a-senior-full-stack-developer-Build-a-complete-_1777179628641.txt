You are a senior full-stack developer. Build a complete production-ready e-commerce web application.

## Tech Stack (STRICT REQUIREMENTS)

* Backend: PHP (no frameworks OR use Laravel if necessary, but prefer clean native PHP MVC)
* Database: MySQL
* Frontend: HTML5, CSS3, Vanilla JavaScript (no heavy frameworks)
* Architecture: MVC structure (Models, Views, Controllers)

---

## Project Overview

Create a full e-commerce platform for a Saudi-based store that sells:

* Clothing (Men, Women, Kids)
* Electronics (Accessories & devices)
* Beauty products & perfumes

The store owns inventory (NOT marketplace).

### 3. Database Design (MySQL)

Create these tables:

* admins (id, email, password)
* categories (id, name)
* products (id, name, description, price, quantity, category_id, image)
* orders (id, customer_name, phone, address, total_price, status, payment_link, created_at)
* order_items (id, order_id, product_id, quantity, price)
